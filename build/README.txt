Loong — AI Agent Desktop App
===========================

INSTALL
1. Double-click "Loong-Setup.exe".
2. It extracts Loong to  %LOCALAPPDATA%\Programs\Loong  and drops a
   "Loong" shortcut on your Desktop.
3. Launch Loong from the Desktop shortcut.

FIRST RUN — IMPORTANT
Loong is an agent: it needs an API key to talk to a language model.
- Open Settings (gear icon) and add your provider API key
  (OpenRouter / OpenAI / Anthropic / Google, or a local Ollama).
- Without a key the app opens but the agent stays offline.

NOTES
- Windows 10 or later.
- Your data lives in  %USERPROFILE%\.loong  (sessions, memory, settings).
- To remove: delete  %LOCALAPPDATA%\Programs\Loong  and the Desktop shortcut.
- This build was packaged for the IASC competition.
