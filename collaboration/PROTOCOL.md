## 4. دورة حياة المهمة

```
PROPOSED → IN_PROGRESS → IMPLEMENTED → SELF_TESTED → IN_REVIEW → ACCEPTED
                                                   ↘ NEEDS_CHANGES
                                                   ↘ UNPROVEN
```

`SELF_TESTED` تعني: الكاتب شغّل الاختبار. `ACCEPTED` تعني: طرف آخر أعاد تشغيله.
`UNPROVEN` تعني: لا دليل قابل لإعادة الإنتاج — وليست نجاحًا ولا فشلًا.
